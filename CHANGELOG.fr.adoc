== v5.2.0.4 — 2026-07-29

* Déplacement de la source CLI de `bin/asciicrystal-revealjs` vers `src/cli.cr` pour que `shards build` n'écrase plus la source par le binaire compilé ; `main` pointe désormais vers `src/cli.cr`.

== v5.2.0.3 — 2026-07-28

* Renommage du shard `crystal-asciidoctor-revealjs` → `asciicrystal-revealjs` (abandon du préfixe `crystal-`, `doctor` devient `crystal`).
* Renommage du module `AsciidoctorRevealjs` → `AsciicrystalRevealjs` ; le namespace du cœur `Asciidoctor::` devient `Asciicrystal::` via la dépendance `asciicrystal` (ex-`crystal-asciidoctor`, `~> 2.0.26.12`).
* Restauration de la source CLI `bin/asciicrystal-revealjs` (un binaire compilé avait été committé par-dessus) et retrait de l'artefact de build du suivi git. Les mentions de provenance de la gem Ruby `asciidoctor-reveal.js` sont conservées.

== v5.2.0.1 — 2026-04-22

* Ajout du linter *ameba* à la CI avec configuration `.ameba.yml` partagée alignée sur l'écosystème Crystal.
* Correction d'une occurrence de `Style/IsAFilter` : remplacement de `any? { |b| b.is_a?(T) }` par `any?(T)` dans `converter.cr`.
